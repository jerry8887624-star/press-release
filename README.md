# 空軍新聞稿生成器

手機優先的新聞稿撰寫工具。免安裝、免登入，資料只存在使用者自己的裝置（localStorage），不上傳任何伺服器。

## 發布到 GitHub Pages
1. 在 GitHub 建立新的 Public 儲存庫（例如 `press-release`）。
2. 按「Add file → Upload files」，把本資料夾**所有檔案與 `ds` 資料夾**拖進去，按 Commit。
3. 到 Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約 1 分鐘後網址為：`https://<你的帳號>.github.io/press-release/`

## 更新
重新上傳覆蓋檔案即可；使用者下次連網開啟會自動取得新版。
